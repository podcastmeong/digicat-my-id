# Sewa Website — Digicat (digicat.my.id)

Situs induk (parent) untuk layanan **Sewa Website** Digicat — berdiri sendiri, terpisah dari toko Digicat.

- **Domain:** digicat.my.id
- **Isi:** landing page statis (Bahasa Indonesia) — penjelasan Sewa Website, 3 paket harga, contoh, dan cara pesan.
- **Paket:** Basic Rp25.000/bln ($2), Professional Rp45.000/bln ($3), Bisnis Rp75.000/bln ($5). Subdomain + hosting termasuk; berhenti bayar, website nonaktif.
- **Pesan:** lewat toko Digicat https://digicat.std.ai.id/ atau email digicat_store@proton.me.
- **Hosting:** GitHub Pages + Cloudflare Pages (sumber di repo ini).
